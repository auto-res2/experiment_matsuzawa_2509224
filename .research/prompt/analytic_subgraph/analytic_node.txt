# Experiment Strategy

────────────────────────────────
EXPERIMENT 1 “Breadth-of-Coverage” corruption & domain–shift benchmark
────────────────────────────────
Goal
• Show that SAUNet’s unified affine view really adapts *every* kind of scale/shift parameter, not only those in norm layers, and that it does so at (near-)zero extra latency.

Set-up
1. Architectures – ConvNeXt-T (layer-scale), ViT-S (LN + QKV scaling), NF-ResNet-50 (no norms), ResNet-50-BN (classic). All loaded with ImageNet-1K frozen weights.
2. Datasets –
   a. ImageNet-C (15 corruptions × 5 severities)
   b. Tiny-ImageNet-C (to test small-scale models)
   c. ImageNet-V2 & ImageNet-A (natural shift / extreme shift)
   d. DomainNet Real → (Sketch, Clipart)
3. Baselines – Source (no TTA), BN-stat, TTN, UnMix-TNS, Tent(1-step), EATA, CoTTA, UniTTA-0G.
4. Hardware – single NVIDIA A100 80 GB; batch = 64 (except video streams, see Exp 3). Mixed-precision (AMP) for all methods, INT8 kernels for SAUNet.
5. Metrics – Top-1 error (↓), relative throughput C(g)=FPSSAUNet/FPSSource (↑), memory overhead (MB), MAC overhead (%), per-sample latency (ms).

Procedure
• For each network, insert SAULayer before every non-linear block (γ,β; layer-scale; qkv scale…).
• Meta-weights θ are the same across datasets; only run-time adaptation is allowed.
• Evaluate each corruption/shift in a single forward pass: 1) load batch → 2) adapt → 3) predict. No gradient storage permitted (fair vis-à-vis Tent/EATA which back-prop).

Success Criterion
SAUNet must (i) beat the best non-back-prop baseline on ≥80 % of corruption severities, (ii) keep C(g)≥0.98 and (iii) add <0.2 % parameters. A win confirms the premise that “forward-only *general* affine adaptation” is both effective and light-weight.

Expected Observation
ConvNeXt-T ImageNet-C error: 47.5 → 37.8 %; ViT-S: 46.1 → 38.4 %; NF-R50: 63.2 → 51.0 %. Latency Δ <2 %. Hence the method is architecture-agnostic and essentially free.

What it Demonstrates
• Addresses Open Problem 1 (beyond normalisers).   
• Matches / surpasses back-prop TTA without the compute hit (Open 3).   
• Establishes *state-of-the-art raw-speed robustness*.

────────────────────────────────
EXPERIMENT 2 Privacy-preserving synthetic meta-training study
────────────────────────────────
Goal
• Prove that SAUNet can be meta-trained *without* any access to the proprietary source dataset yet still delivers almost the same robustness, directly tackling Open Problem 2.

Set-up
1. Choose ViT-S and ConvNeXt-T (high commercial value).  
2. Two training regimes:
   A. SAUNet-Noise – contrastive meta-training on frequency-matched Gaussian noise + RandAugment (no real images).
   B. SAUNet-Source – identical pipeline but with 10 % of ImageNet-1K images (simulating current methods that *do* keep source data).
3. Baseline requiring source data: UniTTA-0G.
4. Hold-out evaluation – license-restricted dataset “Ego4D-Objects” (cannot legally be used for training). Also re-test on ImageNet-C.
5. Privacy leakage test – run a Membership-Inference Attack (MIA) on the two SAUNet variants and on UniTTA-0G.

Metrics
• Final Top-1 error (↓).  
• ΔError = errorNoise − errorSource (pp).  
• MIA-AUC (↓ is safer).  
• Time/energy to meta-train (hours, kWh).

Procedure
• Train both variants for the same wall-clock (2 hrs) on the A100 using 256-sample synthetic batches.  
• Freeze backbone at all times.  
• After training, discard θ gradients; deploy in forward-only mode.

Success Criterion
(i) ΔError ≤ 1 pp on both datasets, (ii) SAUNet-Noise has ≤0.55 MIA-AUC (random ≈ 0.5) while UniTTA ≥0.75, (iii) equal or lower energy cost.

Expected Observation
• Ego4D-Objects Top-1 error: UniTTA 39.2 %, SAUNet-Source 37.6 %, SAUNet-Noise 38.3 % → 0.7 pp gap.  
• MIA-AUC: SAUNet-Noise 0.53 (no leakage), UniTTA 0.78.  
• Training energy: SAUNet 1⁄4 of UniTTA due to synthetic data generation being CPU-bound.

What it Demonstrates
• SAUNet solves privacy & data-retention concerns with almost no performance cost.   
• Validates the synthetic self-supervision recipe as a viable replacement for real data replay.

────────────────────────────────
EXPERIMENT 3 Any-time compute knob & χ² safety guard in streaming video
────────────────────────────────
Goal
• Evaluate Open Problems 3 & 4: (a) dynamic adaptation frequency given latency budgets, (b) mathematically-grounded collapse detection.

Set-up
1. Dataset – ImageNet-VID-C and Ego4D (natural video). Stream frames sequentially (batch = 1) to replicate edge cameras.
2. Latency budgets broadcast every 500 ms, drawn from {3.3 ms, 6.6 ms, 13 ms}; maps to K={1,2,4} Householder terms in SAUNet.
3. Compare –
   • SAUNet (adaptive K + χ² guard)  
   • SAUNet-fixed-K=4 (no budget awareness)  
   • Tent(1-step) – recompute each frame  
   • Source – no adaptation.
4. Intentionally inject two adversarial periods: (i) frame sequence containing only a single class, (ii) sudden label-space shift (vehicles→animals).

Metrics
• Stream-level mAP (↑).  
• Average latency per frame (ms) (↓).  
• %Frames that violate budget, %Frames rolled back by χ² guard, accuracy drop after rollback (pp), number of collapses (entropy→0) (↓).

Procedure
• Run each 3× with different random seeds; log timing with nvtx ranges.  
• Collapse ≜ top-1 entropy <0.01 for ≥20 consecutive frames.

Success Criterion
(i) Adaptive SAUNet meets 100 % latency budgets, (ii) ≤ε = 0.5 % accuracy loss from guard activations, (iii) zero collapses versus ≥1 for Tent or SAUNet-no-guard.

Expected Observation
• mAP: Source 65.2, Tent 71.0 (lat 14 ms), SAUNet-fixed 72.4 (lat 13 ms), SAUNet-adaptive 71.9 (lat 7 ms).  
• χ² guard triggers on the two adversarial windows, rolls back 1.8 % of frames, final accuracy drop 0.2 pp and prevents all collapses; Tent collapses once, SAUNet-no-guard twice.  
• Budget violation: 0 % (adaptive) vs 24 % (fixed-K).

What it Demonstrates
• SAUNet can trade accuracy for speed on-the-fly without manual tuning, fulfilling Open Problem 3.  
• The χ² bound is a robust collapse detector superior to entropy heuristics, solving Open Problem 4 in safety-critical streams.

────────────────────────────────
Combined Take-away
The three complementary experiments—wide-spectrum corruption adaptation, privacy-sensitive meta-training, and real-time video with compute & safety constraints—jointly showcase SAUNet’s effectiveness across *coverage, compliance, and deployability* dimensions, confirming every claimed advantage over prior forward-only TTA methods.
