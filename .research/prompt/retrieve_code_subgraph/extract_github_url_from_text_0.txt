The methodology centers on maintaining nonparametric estimates of the sampler and iteratively updating it towards optimal variance using partial knowledge acquired from sampled neighbors. The optimization of samplers is formulated as an adversary bandit problem, where the 'rewards' are defined as the negative derivatives of the sampling variance. Two bandit algorithms are proposed: 1) GNN-BS, based on the adversary Multi-Armed Bandit (MAB) setting, where a single neighbor (arm) is sampled 'k' times, and the sampler is updated using EXP3. 2) GNN-BS.M, based on MAB with multiple plays, which uses an efficient 'k'-combination sampler (DepRound) to select a 'k'-element subset of neighbors once, and updates the sampler using EXP3.M. For attentive GNNs, adjusted feedback attention values are introduced to approximate the true attention values given only sampled neighborhoods.
