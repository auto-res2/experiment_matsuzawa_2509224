# Paper Outline
GraphSAINT constructs minibatches by directly sampling the training graph G to create subgraphs Gs, on which a full GCN is then built. This inherently resolves the 'neighbor explosion' problem. To address biases introduced by non-identical node/edge sampling probabilities, normalization techniques are developed: aggregator normalization (αu,v = pu,v / pv) for feature propagation and loss normalization (λv = |V| · pv) for minibatch loss. These probabilities are estimated via pre-processing by repeatedly running the sampler. For variance reduction, optimal edge sampling probabilities (pe ∝ |∑ℓ b(ℓ)e|) are derived, and a simplified version (pe ∝ 1/deg(u) + 1/deg(v)) is used. GraphSAINT integrates several light-weight samplers: Random Node Sampler, Random Edge Sampler, Random Walk (RW) Sampler, and Multi-Dimensional Random Walk (MRW) Sampler. All samplers induce the subgraph from sampled nodes/edges to preserve connectivity.
