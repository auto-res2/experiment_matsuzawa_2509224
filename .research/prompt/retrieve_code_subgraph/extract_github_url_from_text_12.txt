# Paper Outline
GraphSAINT's core methodology involves constructing minibatches by first sampling the training graph (G) to create a subgraph (Gs), and then building a full GCN on this subgraph. This contrasts with previous layer-sampling methods. The method incorporates two main techniques: 1) Normalization: Aggregator normalization (αu,v = pu,v/pv) is applied to feature propagation and loss normalization (λv = |V|·pv) to the minibatch loss. These factors are estimated during a pre-processing step by repeatedly running the sampler to count node and edge occurrences. 2) Variance Reduction: Optimal edge sampling probabilities (pe) are derived to minimize the variance of aggregation estimators. A practical simplification sets pe ∝ 1/deg(u) + 1/deg(v) based on graph topology. Four light-weight samplers are integrated: Random node sampler (sampling nodes based on degree distribution), Random edge sampler (sampling edges based on inverse degree sum), Random Walk (RW) based samplers, and Multi-dimensional Random Walk (MRW) samplers. All samplers induce subgraphs from the sampled nodes/edges to maintain connectivity.
